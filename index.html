Mode Local
📝 Ajout rapide : Rédigez votre note puis appuyez sur + ou utilisez les touches Ctrl + Entrée pour valider immédiatement.
🔴 Marquer comme urgent ( ! ) : Commencez le texte d'une note par un point d'exclamation ! pour l'afficher en rouge et la placer en priorité en haut de la liste.
🟡 Marquer une hésitation ( ? ) : Commencez votre note par un point d'interrogation ? pour la mettre en valeur en jaune (idées à vérifier, questions).
🎯 Mode Focus Journalier : Cliquez sur l'icône de cible à côté d'une note pour la réserver à votre journée. Activez le bouton Cible 🎯 en haut de l'écran pour vous concentrer uniquement sur vos tâches du jour.
🖐️ Organisation facile (Glisser-Déposer) : Faites glisser les listes et les notes avec votre souris ou votre doigt pour les réorganiser ou passer une note d'une liste à une autre.
✏️ Modification & Corbeille : Double-cliquez sur une note ou un titre de liste pour modifier son texte. Si vous supprimez une note par erreur, retrouvez-la et restaurez-la dans l'historique de la corbeille en bas d'écran.
